## Limitations

- `unimported` means no landing SQL documents a reason, not necessarily a bug. The earlier `emit_pending_sql` headers (most zones before Ashenvale) list only the items-absent/objective template skips; the importer's other skip reasons (no turn-in, no giver, no spawn) are not in the SQL and appear here. Only the newer `land_zone` zones document every skip.
- Candidate sets use the client DBC subzones; the earlier landings imported the shell's explicit sort set, so some missing rows are import scope rather than content gaps.
- The inventory counts are the #202 proxy denominators, not a chain-by-chain proof.
- The upgrade-from-pinned-baseline convergence is not tested here: the project moved to the clean TDB-built world (#274). Only the fresh clean-world state is reported.
- One landed quest per zone does not prove the quest mechanics, chains or the in-world flow; the per-zone relation checks remain the landing evidence. Geometry prerequisites are #176; phasing and terrain are #180.
